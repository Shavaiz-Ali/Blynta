# Studio editor polish and theme consistency

This pass preserves the approved shell, rail, Project Tools, preview, AI dock, timeline, and panel proportions. Changes are limited to the requested presentation and access refinements.

1. **Theme/sidebar references.** Audited `apps/app/features/dashboard/components/DashboardLayout.tsx`, `apps/studio/features/studio/dashboard/components/StudioShell.tsx`, `packages/ui/src/components/AppWorkspace.tsx`, and `packages/ui/src/styles/theme.css`. Both dashboards consume `AppSidebarItem`; Studio imports the shared theme through its Tailwind globals. No new palette or theme variables were created.
2. **Sidebar tokens.** Removed the editor-only translucent primary selection override. Active items now inherit shared `bg-primary text-primary-foreground`; normal items inherit `text-muted-foreground` and the shared `sidebar-accent` hover colors. The rail retains `bg-sidebar`, now explicitly uses `text-sidebar-foreground` and `border-sidebar-border`, and uses a semantic `ring` keyboard focus outline. Icons inherit the same state foreground as labels. The compact navigation geometry stays intact. Preview, timeline, and AI surfaces already use shared card/background/muted/border/primary tokens, so no additional palette changes were needed there. Existing media content and legacy CSS were not broadly restyled.
3. **Header controls removed.** Removed both icon-only media/properties toggles immediately before Blynta AI, along with their unused icon imports.
4. **Functionality preserved.** The existing tool rail opens/closes the contextual media/tools panel; its own collapse control remains. Clip selection still opens the contextual inspector, and its close control remains. Added an explicit **Open properties** action inside the existing Project settings popover for reopening properties without selecting another clip. It closes AI and respects the existing narrow-screen panel exclusivity. Browser coverage exercises this path.
5. **Blynta AI button.** Text-only, including at mobile widths. Its existing ghost/active treatment stays subordinate to the primary Export action. The right action group no longer shrinks into the project title; Back/title, save status, and actions remain distinct groups.
6. **AI panel identity.** Removed the decorative Sparkles icon. Retained “Blynta AI” and “Your editing assistant,” plus the existing close control. Suggestions, proposal content, composer, scope, send action, and dock architecture are unchanged by this pass. Functional suggestion/proposal icons remain.
7. **Media cards.** Removed the permanent asset-title/type block. The thumbnail now fills the card width at its existing 16:9 aspect ratio, with no metadata footer or empty space reserved for it. Video elements use full-width/height object-cover styling. Existing shared card/button hover, selection ring, and keyboard focus remain.
8. **Video duration.** Only `video` assets render a compact bottom-right overlay, using the existing `formatTime(duration).slice(0, 5)` convention. The badge uses `card/95`, `foreground`, and `border` theme tokens, compact padding, a rounded corner, and tabular numbers. Images show no library duration; timeline clip duration is unaffected.
9. **Accessible titles.** Tooltips retain the asset name and now include media kind plus click/drag guidance. Add and options buttons retain their asset-specific accessible names. The existing context menu, rename dialog, drag payload, add action, removal guard, and reattachment flow remain.
10. **Logo size/alignment.** The existing mark grows from 24 to 28 pixels only in the editor rail, through the logo’s existing size API. `StudioLogo` accepts an optional size and keeps its previous default elsewhere. Its square aspect ratio, centered link container, top spacing, and original asset remain intact. Browser measurements verify 28×28 pixels and horizontal centering.
11. **Shared UI.** Reused `AppSidebarItem`, `AppHeader`, `AppButton`, `AppInput`, `AppPopover`, `AppTooltip`, `AppMediaCard`, `AppDropdown`, `AppDialog`, `AppFileInput`, `AppTabs`, and `AppScrollArea`. No generic primitives, icon libraries, CSS files, or formatting utilities were added.
12. **Files changed in this pass.** `apps/studio/components/common/StudioLogo.tsx`; editor `components/EditorToolbar.tsx`, `media/MediaPanel.tsx`, `media/MediaItem.tsx`, `ai/AIPanel.tsx`; `apps/studio/scripts/test-workspace.mjs`; this report. Earlier redesign changes remain in the working tree and are outside this polish pass.
13. **Lint.** `pnpm --filter @blynta/studio lint` passed.
14. **Typecheck.** `pnpm --filter @blynta/studio typecheck` passed.
15. **Build.** `MAIN_APP_URL=https://app.blynta.com pnpm --filter @blynta/studio build` passed, including compilation, TypeScript, and static page generation. The URL was supplied only to the command environment; no environment files were changed.

The existing editor/auth regression suite passed. Workspace browser checks cover layout across desktop/mobile widths, media metadata/duration rules, logo geometry, removed header icons, reopened properties, inspector/AI transitions, resize persistence, clip history, autosave, and export UI. API responses in this suite are mocked; the media mock refreshes source URLs after serialized autosave, matching the existing URL-stripping behavior. Light/dark sidebar colors are compared against computed shared theme tokens.
